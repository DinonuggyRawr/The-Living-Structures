# Phase 5 educational interpretation

- Min/max binary heaps are backed by zero-based arrays, shown as a connected tree for intuition. Parent `floor((i-1)/2)` and children `2i+1`, `2i+2`; heap order does not imply sorted iteration. `BUILD/HEAPIFY` performs bottom-up sifts. Insert/extract are O(log n) worst-case, heapify O(n).
- Graph vertices are A-I, maximum 9, with authoritative adjacency matrix. Directed and undirected data are not silently converted. Edges drawn reflect actual modeled matrix entries. BFS uses FIFO with discovery on enqueue. DFS uses an explicit LIFO frontier and sorted-neighbor ordering. The familiar O(V+E) traversals assume adjacency lists; scanning all V columns per visited vertex in this teaching matrix is O(V^2) worst-case.
- Hashing is a fixed 7-bucket integer-key SET (no associated values). Negative keys use C-safe normalized modulo. Separate chaining uses bounded conceptual collision lists; linear probing uses EMPTY, OCCUPIED and DELETED tombstone states. This is not a general-purpose malloc-backed C hash library. Hash lookup is O(1) expected under favorable hashing/load but O(n) worst-case.
- Full C11/WASM functions are narrower: min-heap insert/extract, graph BFS/DFS over directed matrix, hash linear insert/find/remove. Visual max heaps and separate chaining do not yet have matching compiler-backed full-function exercises. The harness supplies struct definitions and a `hash_bucket` helper; students implement exactly the selected function. Graph DFS reference includes a static recursive helper.
- The C compiler and Wasmtime already present in the project are reused: opt-in only, toolchain check, isolated WASM per test, no granted directory access, finite memory/fuel/time/process limits. Zig and Wasmtime are host-native trusted tooling; this is not a hardened hostile-code service.
- The app never executes a real network operation or creates arbitrary native student binaries. Modeled code traces are educational examples, not a C interpreter. Symbolic node edges are derived from deterministic state.
- All Phase 5 practice, trace predictions and C test credits are ephemeral session-only data, separate from legacy saves and Academy progress. Guided completion, structure traces and finite reference tests never confer certified C mastery.
- Buildings are educational subject hubs and future discoverable 3D destinations. This phase implements a left-side subject directory and useful visual links; physical 3D clicking, walkthrough entrances, elaborate interiors and achievements remain future work.
