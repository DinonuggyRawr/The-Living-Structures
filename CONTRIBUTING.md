# Contributing

The main development goal is accurate, beginner-friendly visual instruction in C11 and Computing II data structures. Preserve the distinction between visual demonstrations, guided practice and independent compiler-backed evidence.

Before contributing, open an issue describing the learning objective, regression risk and affected lab. Prefer focused changes; preserve Unity save compatibility, Editor compilation, offline/no-remote execution, and the established test suite. Include specific screenshots for new UI and document any C11 behavioral simplifications. Do not submit security exploits publicly; use private vulnerability reporting.

The project owner has not yet selected a repository license in this publication kit. Check the repository's current LICENSE and contribution terms before sending copyrighted contributions.
